# Free Market en vivo

Ofertas del Free Market que va leyendo MSCE (MapleStory Market Scanner), en tiempo real.

La página lee una tabla de Supabase con la clave publicable, que solo permite leer.
MSCE sube las ofertas con su propia clave de escritura, que no está en este repositorio.

Se publica con GitHub Pages: Settings → Pages → Deploy from a branch → `main`, carpeta `/ (root)`.
